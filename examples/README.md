# Aperture LLM Gateway 使用示例

本目录包含了使用Aperture LLM Gateway的示例代码，展示了如何使用系统的核心功能。

## 示例文件

### 1. 基本使用示例 (`basic_usage.py`)

这个示例展示了如何初始化和使用GatewayService来处理用户查询，包括：
- 初始化所有必要的服务
- 处理单个用户查询
- 批量处理多个用户查询
- 查看处理结果

**使用方法：**
```bash
python examples/basic_usage.py
```

### 2. 高级使用示例 (`advanced_usage.py`)

这个示例展示了如何使用RoutingService的高级功能，包括：
- 初始化路由服务
- 评估不同查询的意图复杂度
- 计算模型权重
- 测试并发控制
- 测试熔断执行机制

**使用方法：**
```bash
python examples/advanced_usage.py
```

## 系统要求

使用这些示例需要以下依赖：

1. Python 3.8+
2. 项目依赖包（见项目根目录的requirements.txt）
3. 特别需要：
   - tenacity (用于熔断执行机制)
   - scikit-learn (用于意图识别)
   - numpy (用于向量计算)

## 安装依赖

在项目根目录运行：

```bash
pip install -r requirements.txt
```

## 示例输出说明

### 基本使用示例输出

运行 `basic_usage.py` 会输出：
- 服务初始化状态
- 单个查询的处理结果，包括意图识别、使用的模型、回复内容等
- 批量查询的处理结果，展示多个查询的处理情况

### 高级使用示例输出

运行 `advanced_usage.py` 会输出：
- 服务初始化状态
- 不同查询的意图复杂度评估结果
- 模型权重计算结果，展示不同复杂度下的权重变化
- 并发控制测试结果，展示活跃请求计数
- 熔断执行机制测试结果
- 优先级模型列表，展示根据复杂度排序的模型

## 自定义配置

如果需要自定义系统配置，可以修改 `app/config/settings.py` 文件，包括：
- 路由权重配置
- 缓存阈值配置
- 意图关键词配置
- 模型目录配置

## 注意事项

1. 这些示例使用的是内存存储库（MemoryRepository），适用于测试和演示
2. 实际生产环境中，建议使用持久化存储
3. 示例中的模型响应是模拟的，实际使用时会调用真实的模型API
4. 运行示例前，请确保已经安装了所有必要的依赖

## 故障排除

如果运行示例时遇到问题：

1. 检查依赖是否正确安装
2. 确保Python版本符合要求
3. 检查项目结构是否正确
4. 查看错误信息，定位具体问题
