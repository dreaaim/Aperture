# Aperture 模型服务架构重新设计

## 1. 架构设计原则

### 1.1 核心理念：模型优先
**设计原则**：先从模型清单选择模型，再从模型对应的服务商列表选择服务商

**优势**：
- 解耦模型和服务商的关系
- 支持一个模型在多个服务商上运行
- 更灵活的成本优化和故障转移
- 更好的模型能力管理

### 1.2 架构对比

#### 旧架构（服务商优先）
```
用户请求 → 选择服务商 → 选择模型 → 调用
```
**问题**：
- 模型和服务商强耦合
- 难以支持多服务商部署同一模型
- 成本优化受限

#### 新架构（模型优先）
```
用户请求 → 选择模型 → 选择服务商 → 调用
```
**优势**：
- 模型和服务商解耦
- 支持多服务商部署
- 成本优化更灵活

### 3.1 模型选择服务（Model Selection Service）

```python
class ModelSelectionService:
    """模型选择服务"""
    
    def __init__(self):
        self.model_catalog = ModelCatalog()
        self.provider_catalog = ProviderCatalog()
        self.mapping_manager = ModelProviderMappingManager()
        self.cost_optimizer = CostOptimizationService()
    
    async def select_model(self, query: str, intent: str, complexity: float, 
                          requirements: Dict) -> Tuple[ModelDefinition, ProviderDefinition]:
        """选择模型和服务商
        
        Args:
            query: 用户查询
            intent: 意图分类
            complexity: 复杂度评分
            requirements: 其他需求（如预算限制、特性要求等）
            
        Returns:
            (模型定义, 服务商定义)
        """
        # 第一步：选择合适的模型
        model = await self._select_best_model(intent, complexity, requirements)
        
        # 第二步：从该模型的服务商列表中选择最优服务商
        provider = await self._select_best_provider(model.model_id, requirements)
        
        return model, provider
    
    async def _select_best_model(self, intent: str, complexity: float, 
                                 requirements: Dict) -> ModelDefinition:
        """选择最优模型"""
        # 获取候选模型列表
        candidates = self.model_catalog.get_models_by_intent(intent)
        
        # 过滤符合要求的模型
        filtered_models = self._filter_models(candidates, requirements)
        
        # 评分排序
        scored_models = []
        for model in filtered_models:
            score = await self._calculate_model_score(model, intent, complexity, requirements)
            scored_models.append((model, score))
        
        # 选择评分最高的模型
        best_model = max(scored_models, key=lambda x: x[1])[0]
        return best_model
    
    async def _select_best_provider(self, model_id: str, requirements: Dict) -> ProviderDefinition:
        """选择最优服务商"""
        # 获取该模型的所有服务商映射
        mappings = self.mapping_manager.get_provider_mappings(model_id)
        
        # 过滤可用的服务商
        available_providers = []
        for mapping in mappings:
            if not mapping.enabled:
                continue
            
            provider = self.provider_catalog.get_provider(mapping.provider_id)
            if provider and provider.enabled:
                # 检查配额
                if mapping.quota_limit and mapping.quota_used >= mapping.quota_limit:
                    continue
                available_providers.append((provider, mapping))
        
        if not available_providers:
            raise NoAvailableProviderError(f"No available provider for model {model_id}")
        
        # 评分排序
        scored_providers = []
        for provider, mapping in available_providers:
            score = await self._calculate_provider_score(provider, mapping, requirements)
            scored_providers.append((provider, mapping, score))
        
        # 选择评分最高的服务商
        best_provider = max(scored_providers, key=lambda x: x[2])[0]
        return best_provider
    
    async def _calculate_model_score(self, model: ModelDefinition, intent: str, 
                                    complexity: float, requirements: Dict) -> float:
        """计算模型评分"""
        # 能力匹配因子（权重0.4）
        capability_score = self._calculate_capability_score(model, intent, complexity)
        
        # 成本因子（权重0.3）
        cost_score = self._calculate_model_cost_score(model, requirements)
        
        # 质量因子（权重0.2）
        quality_score = self._calculate_quality_score(model)
        
        # 可用性因子（权重0.1）
        availability_score = self._calculate_availability_score(model)
        
        # 综合评分
        total_score = (
            0.4 * capability_score +
            0.3 * cost_score +
            0.2 * quality_score +
            0.1 * availability_score
        )
        
        return total_score
    
    async def _calculate_provider_score(self, provider: ProviderDefinition, 
                                       mapping: ModelProviderMapping, 
                                       requirements: Dict) -> float:
        """计算服务商评分"""
        # 成本因子（权重0.4）
        cost_score = self._calculate_provider_cost_score(provider, mapping)
        
        # 性能因子（权重0.3）
        performance_score = self._calculate_performance_score(provider)
        
        # 可靠性因子（权重0.2）
        reliability_score = self._calculate_reliability_score(provider)
        
        # 免费优先级因子（权重0.1）
        free_priority_score = self._calculate_free_priority_score(provider, mapping)
        
        # 综合评分
        total_score = (
            0.4 * cost_score +
            0.3 * performance_score +
            0.2 * reliability_score +
            0.1 * free_priority_score
        )
        
        return total_score
```

```python
class ModelCatalogManager:
    """模型清单管理器"""
    
    def __init__(self, config_file: str = "config/models.yaml"):
        self.config_file = config_file
        self.models: Dict[str, ModelDefinition] = {}
        self.load_config()
    
    def load_config(self):
        """加载模型配置"""
        with open(self.config_file, 'r', encoding='utf-8') as f:
            config_data = yaml.safe_load(f)
        
        for model_id, model_config in config_data.get('models', {}).items():
            self.models[model_id] = ModelDefinition(**model_config)
    
    def get_model(self, model_id: str) -> Optional[ModelDefinition]:
        """获取模型定义"""
        return self.models.get(model_id)
    
    def get_models_by_intent(self, intent: str) -> List[ModelDefinition]:
        """根据意图获取模型列表"""
        # 根据意图映射到能力需求
        intent_capability_map = {
            "code": ["code", "reasoning"],
            "reasoning": ["reasoning"],
            "creative": ["creative"],
            "chat": [],
            "general": []
        }
        
        required_capabilities = intent_capability_map.get(intent, [])
        
        # 过滤具备所需能力的模型
        suitable_models = []
        for model in self.models.values():
            if not model.enabled:
                continue
            
            if required_capabilities:
                if all(cap in model.capabilities for cap in required_capabilities):
                    suitable_models.append(model)
            else:
                suitable_models.append(model)
        
        return suitable_models
    
    def get_models_by_capability(self, capability: str) -> List[ModelDefinition]:
        """根据能力获取模型列表"""
        return [
            model for model in self.models.values()
            if model.enabled and capability in model.capabilities
        ]
```

```python
class ProviderCatalogManager:
    """服务商清单管理器"""
    
    def __init__(self, config_file: str = "config/providers.yaml"):
        self.config_file = config_file
        self.providers: Dict[str, ProviderDefinition] = {}
        self.load_config()
    
    def load_config(self):
        """加载服务商配置"""
        with open(self.config_file, 'r', encoding='utf-8') as f:
            config_data = yaml.safe_load(f)
        
        # 合并所有类型的服务商
        all_providers = {}
        all_providers.update(config_data.get('first_party', {}))
        all_providers.update(config_data.get('cloud_gateways', {}))
        all_providers.update(config_data.get('third_party', {}))
        all_providers.update(config_data.get('free_providers', {}))
        
        for provider_id, provider_config in all_providers.items():
            # 替换环境变量
            self._replace_env_vars(provider_config)
            self.providers[provider_id] = ProviderDefinition(**provider_config)
    
    def _replace_env_vars(self, config: Dict):
        """替换环境变量"""
        for key, value in config.items():
            if isinstance(value, str) and value.startswith('${') and value.endswith('}'):
                env_var = value[2:-1]
                config[key] = os.getenv(env_var, '')
    
    def get_provider(self, provider_id: str) -> Optional[ProviderDefinition]:
        """获取服务商定义"""
        return self.providers.get(provider_id)
    
    def get_enabled_providers(self) -> List[ProviderDefinition]:
        """获取所有启用的服务商"""
        return [
            provider for provider in self.providers.values()
            if provider.enabled
        ]
```

```python
class ModelProviderMappingManager:

    def __init__(self, config_file: str = "config/model_provider_mappings.yaml"):
        self.config_file = config_file
        self.mappings: Dict[str, List[ModelProviderMapping]] = {}  # model_id -> [mappings]
        self.load_config()
    
    def load_config(self):
        """加载映射关系配置"""
        with open(self.config_file, 'r', encoding='utf-8') as f:
            config_data = yaml.safe_load(f)
        
        for mapping_config in config_data.get('mappings', []):
            mapping = ModelProviderMapping(**mapping_config)
            
            if mapping.model_id not in self.mappings:
                self.mappings[mapping.model_id] = []
            
            self.mappings[mapping.model_id].append(mapping)
    
    def get_provider_mappings(self, model_id: str) -> List[ModelProviderMapping]:
        """获取模型的所有服务商映射"""
        return self.mappings.get(model_id, [])
    
    def update_quota_usage(self, model_id: str, provider_id: str, tokens_used: int):
        """更新配额使用情况"""
        mappings = self.get_provider_mappings(model_id)
        for mapping in mappings:
            if mapping.provider_id == provider_id:
                mapping.quota_used += tokens_used
                mapping.last_updated = time.time()
                break
```

```python
class EnhancedRoutingService:
    """增强的路由服务（模型优先）"""
    
    def __init__(self):
        self.model_selector = ModelSelectionService()
        self.adapter_factory = UnifiedAdapterFactory()
        self.usage_tracker = UsageTracker()
    
    async def route_request(self, query: str, user_id: str, 
                           requirements: Optional[Dict] = None) -> Dict:
        """路由请求（模型优先）"""
        
        # 1. 意图分类和复杂度评估
        intent, complexity = await self._analyze_query(query)
        
        # 2. 选择模型和服务商
        model, provider = await self.model_selector.select_model(
            query=query,
            intent=intent,
            complexity=complexity,
            requirements=requirements or {}
        )
        
        # 3. 获取适配器
        adapter = self.adapter_factory.get_adapter(provider, model)
        
        # 4. 执行请求
        response = await adapter.chat_completion(
            messages=[{"role": "user", "content": query}],
            model=model.model_id
        )
        
        # 5. 记录使用情况
        self.usage_tracker.record_usage(
            model_id=model.model_id,
            provider_id=provider.provider_id,
            tokens_used=response.get('tokens_used', 0),
            cost=response.get('cost', 0)
        )
        
        return {
            "response": response,
            "model": model.model_id,
            "provider": provider.provider_id,
            "intent": intent,
            "complexity": complexity
        }
```

```python
async def route_with_fallback(self, query: str, intent: str, 
                             complexity: float, requirements: Dict) -> Dict:
    """带故障转移的路由"""
    
    # 1. 选择模型
    model = await self.model_selector._select_best_model(intent, complexity, requirements)
    
    # 2. 获取该模型的所有服务商（按优先级排序）
    mappings = self.mapping_manager.get_provider_mappings(model.model_id)
    mappings.sort(key=lambda m: m.priority)
    
    # 3. 依次尝试服务商
    last_error = None
    for mapping in mappings:
        if not mapping.enabled:
            continue
        
        provider = self.provider_catalog.get_provider(mapping.provider_id)
        if not provider or not provider.enabled:
            continue
        
        try:
            # 尝试调用
            adapter = self.adapter_factory.get_adapter(provider, model)
            response = await adapter.chat_completion(
                messages=[{"role": "user", "content": query}],
                model=mapping.provider_model_id
            )
            
            # 成功，返回结果
            return {
                "response": response,
                "model": model.model_id,
                "provider": provider.provider_id
            }
        except Exception as e:
            # 记录错误，继续尝试下一个服务商
            last_error = e
            logger.warning(f"Provider {provider.provider_id} failed: {e}")
            continue
    
    # 所有服务商都失败，抛出异常
    raise AllProvidersFailedError(f"All providers failed for model {model.model_id}: {last_error}")
```

## 6. 优势总结

### 6.1 架构优势
- **解耦模型和服务商**：模型定义和服务商配置独立管理
- **灵活的多服务商支持**：一个模型可以在多个服务商上运行
- **智能故障转移**：自动切换到备用服务商
- **成本优化更精细**：可以选择不同服务商的最优价格

### 6.2 运维优势
- **配置管理清晰**：三个配置文件各司其职
- **易于扩展**：添加新模型或服务商只需修改配置
- **故障隔离**：单个服务商故障不影响整体服务
- **成本监控精确**：可以精确追踪每个模型在每个服务商上的成本

### 6.3 业务优势
- **更好的用户体验**：自动选择最优模型和服务商
- **成本控制灵活**：可以根据预算选择不同服务商
- **高可用性**：多服务商部署提高可用性
- **快速响应**：模型优先选择减少决策时间
