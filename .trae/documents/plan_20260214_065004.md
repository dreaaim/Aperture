# 模型服务商扩展优化开发计划

## 任务概述

根据 `design/模型服务提供商` 目录中的设计文档，扩展优化模型服务模块，使所有支持 OpenAI 协议的服务商能够统一通过 OpenAI 标准接入。

## 分析结果

### 支持 OpenAI 兼容协议的服务商

根据设计文档分析，以下服务商完全支持 OpenAI 兼容 API：

**免费服务商**：
- OpenRouter - base_url: https://openrouter.ai/api/v1
- Groq - base_url: https://api.groq.com/openai/v1
- Cerebras - base_url: https://api.cerebras.ai/v1
- Google AI Studio - 支持 OpenAI 协议
- NVIDIA NIM - 支持 OpenAI 协议
- Mistral - 支持 OpenAI 协议
- GitHub Models - 支持 OpenAI 协议
- Cloudflare Workers AI - 支持 OpenAI 协议
- HuggingFace Inference - 支持 OpenAI 协议

**付费服务商**：
- Fireworks - 支持 OpenAI 协议
- Novita - 支持 OpenAI 协议
- Hyperbolic - 支持 OpenAI 协议
- SambaNova - 支持 OpenAI 协议

## 详细开发计划

### 1. 增强 OpenAI 适配器

**修改文件**: `app/adapters/protocols/openai_adapter.py`

**新增功能**:
- 支持自定义 headers（如 OpenRouter 的 HTTP-Referer, X-Title）
- 支持服务商特定的响应格式处理
- 支持错误码映射和重试策略
- 支持模型名称映射

### 2. 更新 providers.yaml 配置

**修改文件**: `config/providers.yaml`

**新增服务商配置**:

```yaml
free_providers:
  # Groq - 超低延迟推理
  groq:
    provider_id: "groq"
    provider_name: "Groq"
    base_url: "https://api.groq.com/openai/v1"
    api_key: "${GROQ_API_KEY}"
    supported_protocols: ["openai"]
    pricing_tier: "free"
    features: ["streaming", "audio_transcription"]
    
  # Cerebras - 极速推理
  cerebras:
    provider_id: "cerebras"
    provider_name: "Cerebras"
    base_url: "https://api.cerebras.ai/v1"
    api_key: "${CEREBRAS_API_KEY}"
    supported_protocols: ["openai"]
    pricing_tier: "free"
    
  # NVIDIA NIM
  nvidia_nim:
    provider_id: "nvidia_nim"
    provider_name: "NVIDIA NIM"
    base_url: "https://integrate.api.nvidia.com/v1"
    api_key: "${NVIDIA_API_KEY}"
    supported_protocols: ["openai"]
    
  # Mistral
  mistral:
    provider_id: "mistral"
    provider_name: "Mistral AI"
    base_url: "https://api.mistral.ai/v1"
    api_key: "${MISTRAL_API_KEY}"
    supported_protocols: ["openai"]
    
  # GitHub Models
  github_models:
    provider_id: "github_models"
    provider_name: "GitHub Models"
    base_url: "https://models.inference.ai.azure.com"
    api_key: "${GITHUB_TOKEN}"
    supported_protocols: ["openai"]
```

### 3. 创建服务商配置模板

**新建文件**: `config/providers_template.yaml`

包含所有服务商的配置模板，方便用户快速配置。

### 4. 更新适配器工厂

**修改文件**: `app/adapters/adapter_factory.py`

确保工厂能够正确识别和创建 OpenAI 兼容服务商的适配器实例。
