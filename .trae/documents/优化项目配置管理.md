# 配置优化计划

## 目标
优化项目的配置管理，添加缺失的模块管理，并输出 `config_example.yaml` 文件。

## 改进内容

### 1. 数据库连接管理
- **当前问题**：只使用单一的 `database_url` 字符串，不够灵活
- **改进方案**：
  - 添加 `DatabaseSettings` 类，包含详细的数据库连接参数
  - 支持不同类型的数据库（PostgreSQL、MySQL等）
  - 提供独立的配置项：host、port、database、username、password
  - 保持向后兼容，仍支持 `database_url` 覆盖

### 2. 模型服务商管理
- **当前问题**：缺少模型服务商的详细配置
- **改进方案**：
  - 添加 `ModelProviderSettings` 类，管理不同服务商的配置
  - 支持多个模型服务商（OpenAI、Anthropic、Google等）
  - 为每个服务商提供：base_url、api_key、timeout、rate_limit等
  - 支持服务商级别的配置覆盖

### 3. YAML 配置文件支持
- **当前问题**：只支持 Python 代码配置和环境变量
- **改进方案**：
  - 添加 YAML 配置文件支持，优先级：环境变量 > YAML 文件 > 默认值
  - 创建 `config_example.yaml` 文件，作为配置模板
  - 支持配置热重载

## 技术实现

### 1. 修改 `app/config/settings.py`
- 添加 `DatabaseSettings` 类
- 添加 `ModelProviderSettings` 类
- 修改 `Settings` 类，集成新的配置项
- 添加 YAML 文件加载逻辑

### 2. 创建 `config_example.yaml`
- 包含所有配置项的示例值
- 提供详细的注释说明
- 按照模块组织配置结构

### 3. 保持向后兼容
- 确保现有代码不需要修改
- 支持通过环境变量覆盖配置
- 保持 `database_url` 的优先级高于新的数据库配置项

## 配置结构

### Python 配置结构
```python
class DatabaseSettings(BaseSettings):
    host: str = "localhost"
    port: int = 5432
    database: str = "aperture"
    username: str = "postgres"
    password: str = "postgres"
    driver: str = "postgresql"

class ModelProviderSettings(BaseSettings):
    providers: Dict[str, Dict[str, Any]] = {
        "openai": {
            "base_url": "https://api.openai.com/v1",
            "api_key": "",
            "timeout": 30,
            "rate_limit": 60
        },
        # 其他服务商...
    }

class Settings(BaseSettings):
    database: DatabaseSettings = DatabaseSettings()
    model_providers: ModelProviderSettings = ModelProviderSettings()
    # 现有配置项...
```

### YAML 配置结构
```yaml
database:
  host: localhost
  port: 5432
  database: aperture
  username: postgres
  password: postgres
  driver: postgresql

model_providers:
  openai:
    base_url: https://api.openai.com/v1
    api_key: ""
    timeout: 30
    rate_limit: 60
  anthropic:
    base_url: https://api.anthropic.com/v1
    api_key: ""
    timeout: 30
    rate_limit: 60

# 其他配置项...
```

## 预期效果
- 配置管理更加灵活和模块化
- 支持详细的数据库连接配置
- 支持多个模型服务商的配置管理
- 提供 YAML 配置文件模板，便于部署和管理
- 保持向后兼容，不影响现有代码
