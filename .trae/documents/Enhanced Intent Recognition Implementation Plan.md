# 完善意图识别部分的实现计划

## 目标
实现一个增强的意图识别系统，结合关键词匹配、向量检索和大模型识别，以提高意图识别的准确性和可靠性。

## 已完成的工作
1. 创建了 `EnhancedIntentService` 类，实现了混合意图识别架构
2. 实现了基于 tf-idf 和 n-gram 的关键词匹配功能
3. 实现了向量检索功能（占位符实现，使用随机向量）
4. 实现了 RRF 混合检索和阈值判断逻辑
5. 实现了通过大模型进行意图识别的功能（占位符实现）
6. 集成到了 `container.py` 中，保持向后兼容

## 待完成的工作

## 技术实现要点

### 关键词匹配优化
- 使用 `TfidfVectorizer` 实现 tf-idf 权重计算
- 支持 n-gram（1-2 元语法）以捕捉短语特征
- 计算查询与意图类别的余弦相似度

### 向量检索实现
- 使用嵌入模型生成文本向量
- 计算查询向量与意图类别向量的相似度
- 实现 topk 相似度匹配

### RRF 混合检索
- 融合关键词匹配和向量检索的结果
- 使用 RRF 算法计算最终排序
- 设置 0.8 的阈值判断是否直接采纳结果

### 大模型意图识别
- 构建包含查询和检索结果的提示词
- 调用大模型进行最终意图判断
- 解析大模型响应，提取意图和置信度

## 预期效果
- 提高意图识别的准确性和覆盖范围
- 减少大模型调用，降低成本和延迟
- 保持系统的可扩展性和可维护性
