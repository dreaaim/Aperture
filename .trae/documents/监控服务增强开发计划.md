# 监控服务增强开发计划

## 任务概述

根据待办事项清单，需要完成 P0 优先级的"监控服务增强"任务，包括三个主要部分：

1. 扩展成本记录功能
2. 实现配额管理
3. 实现使用量跟踪器

## 详细开发计划

### 1. 扩展成本记录功能

**文件**: `app/services/monitoring_service.py`

**新增功能**:

* `record_cost_with_details()` - 记录详细成本信息（已支持 intent, complexity）

* `get_cost_summary_by_period()` - 按时间段汇总成本统计（小时/天/周/月）

* `analyze_cost_trend()` - 成本趋势分析

* `detect_cost_anomaly()` - 成本异常检测

**实现要点**:

* 使用时间窗口聚合成本数据

* 实现移动平均算法进行趋势分析

* 使用标准差方法检测异常成本

### 2. 实现配额管理器

**新文件**: `app/services/quota_manager.py`

**类设计**:

```python
class QuotaManager:
    - __init__(self, monitoring_service, settings)
    - check_quota(user_id, model_id) -> QuotaStatus
    - track_usage(user_id, model_id, tokens, cost)
    - get_quota_alerts() -> List[QuotaAlert]
    - generate_quota_report(user_id) -> QuotaReport
    - reset_daily_quotas()
    - reset_monthly_quotas()
```

**数据类**:

* `QuotaStatus` - 配额状态信息

* `QuotaAlert` - 配额预警信息

* `QuotaReport` - 配额使用报告

**预警机制**:

* 80% 配额使用 - 警告级别

* 90% 配额使用 - 严重级别

* 100% 配额使用 - 紧急级别

### 3. 实现使用量跟踪器

**新文件**: `app/services/usage_tracker.py`

**类设计**:

```python
class UsageTracker:
    - __init__(self, monitoring_service, provider_manager)
    - track_request(provider_id, model_id, tokens, cost)
    - get_daily_usage(provider_id) -> DailyUsage
    - get_monthly_usage(provider_id) -> MonthlyUsage
    - monitor_free_quota(provider_id) -> FreeQuotaStatus
    - predict_usage(provider_id, days) -> UsagePrediction
    - get_usage_report() -> UsageReport
```

**数据类**:

* `DailyUsage` - 每日使用量统计

* `MonthlyUsage` - 每月使用量统计

* `FreeQuotaStatus` - 免费额度状态

* `UsagePrediction` - 使用量预测

**预测算法**:

* 基于历史数据的线性回归预测

* 考虑工作日/周末的使用模式差异

### 4. 集成到现有系统

**修改文件**:

* `app/services/routing_service.py` - 集成 QuotaManager 进行配额检查

* `app/services/gateway_service.py` - 集成 UsageTracker 进行使用量跟踪

### 5. 添加配置支持

**修改文件**: `app/config/settings.py`

**新增配置**:

```python
class QuotaSettings(BaseSettings):
    warning_threshold: float = 0.8
    critical_threshold: float = 0.9
    emergency_threshold: float = 1.0
    daily_reset_hour: int = 0
    monthly_reset_day: int = 1

class UsageTrackerSettings(BaseSettings):
    prediction_window_days: int = 7
    history_window_days: int = 30
    free_quota_check_interval: int = 300
```
