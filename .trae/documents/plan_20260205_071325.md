### 3.1 成本优化服务

#### 3.1.1 多维度评分算法
```python
def calculate_model_score(self, model, intent, complexity, quota_usage):
    # 成本因子（权重0.4）
    cost_factor = self._calculate_cost_factor(model)
    
    # 性能因子（权重0.3）
    performance_factor = self._calculate_performance_factor(model)
    
    # 能力匹配因子（权重0.2）
    capability_factor = self._calculate_capability_factor(model, intent, complexity)
    
    # 配额健康度因子（权重0.1）
    quota_factor = self._calculate_quota_factor(model, quota_usage)
    
    # 综合评分
    total_score = (0.4 * cost_factor + 
                  0.3 * performance_factor + 
                  0.2 * capability_factor + 
                  0.1 * quota_factor)
    
    return total_score
```

```python
async def get_current_price(self, model_id):
    # 检查缓存
    if model_id in self.price_cache:
        cached_price, timestamp = self.price_cache[model_id]
        if time.time() - timestamp < self.cache_ttl:
            return cached_price
    
    # 从多个源获取价格
    prices = []
    for source in self.price_sources:
        try:
            price = await source.get_price(model_id)
            if price is not None:
                prices.append(price)
        except Exception as e:
            logger.warning(f"Failed to get price from {source}: {e}")
    
    # 取最低价格
    current_price = min(prices) if prices else self._get_default_price(model_id)
    
    # 更新缓存
    self.price_cache[model_id] = (current_price, time.time())
    
    return current_price
```

```python
def record_cost(self, model_id, user_id, tokens_used, request_id, intent, complexity):

        model_id=model_id,

        tokens_used=tokens_used,
```

## 6. 风险与应对

### 6.1 技术风险
- **价格API不稳定**：实现多源价格获取和缓存机制
- **路由算法复杂度**：采用渐进式优化，先实现基础版本
- **性能影响**：通过异步处理和缓存减少性能开销

### 6.2 业务风险
- **服务商政策变化**：建立灵活的服务商管理机制
- **成本预测不准确**：采用机器学习模型提高预测准确性
- **用户体验下降**：设置性能阈值，确保用户体验不受影响

## 7. 实施优先级

1. **第一阶段**：配置系统扩展 → 监控服务增强 → 数据库模型扩展
2. **第二阶段**：成本优化服务 → 路由服务集成 → 容器服务扩展
3. **第三阶段**：缓存服务扩展 → 测试覆盖 → 性能优化
